# النسخة الثابتة — موقع محمد عبدالقادر

هذا المجلد موقع HTML كامل جاهز للرفع على GitHub Pages. لا يحتاج PHP ولا قاعدة
بيانات ولا أي إعداد على الخادم.

## المحتويات

```
index.html          يحوّل الزائر إلى لغته تلقائياً
en/  ar/            نسختا الموقع (٢١ صفحة لكل لغة)
build/              ملفات CSS و JS
uploads/            صورك (فارغ الآن)
404.html            صفحة الخطأ
sitemap.xml         خريطة الموقع لمحركات البحث
.nojekyll           ضروري — يمنع GitHub من معالجة الملفات
```

## قبل الرفع: خطوتان

**١. اضبط عنوان الموقع** (مرة واحدة، ومرة أخرى عند شراء الدومين):

```bash
bash ../scripts/set-site-url.sh https://USERNAME.github.io
```

هذا يعدّل روابط canonical وhreflang وخريطة الموقع فقط — الروابط بين الصفحات نسبية
ولا تحتاج تغييراً.

**٢. فعّل نموذج التواصل:** سجّل مجاناً في <https://web3forms.com> ببريدك، وستصلك
`Access Key`. استبدلها في كل الصفحات:

```bash
grep -rl WEB3FORMS_ACCESS_KEY . | xargs sed -i 's/WEB3FORMS_ACCESS_KEY/مفتاحك-هنا/g'
```

قبل ضبط المفتاح لن يعمل النموذج — لكن أزرار البريد وواتساب في الصفحة تعمل دائماً.

## تعديل المحتوى

كل النصوص مكتوبة مباشرة داخل ملفات HTML. عدّل الملف المناسب:

| ما تريد تغييره | الملف |
|---|---|
| العنوان الرئيسي والإحصاءات | `en/index.html` و `ar/index.html` |
| خدمة معيّنة | `en/services/اسم-الخدمة/index.html` |
| الأسعار | ابحث عن `$349` في ملفات `packages` و `services` |
| السيرة الذاتية | `en/resume/index.html` |
| بيانات التواصل والتذييل | موجودة في كل صفحة — استخدم بحث واستبدال |

**تنبيه مهم:** هذه النسخة منفصلة عن مشروع لارافيل. أي تعديل تكتبه هنا لن ينتقل
تلقائياً إلى النسخة الكاملة، وسيلزمك إدخاله مرة واحدة من لوحة التحكم عندما تنتقل
إلى الاستضافة الكاملة. لتقليل هذا العمل: احتفظ بقائمة بما غيّرته، أو أرسل لي
التعديلات وسأطبّقها على النسختين معاً.
