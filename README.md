# النسخة الثابتة — موقع محمد عبدالقادر

موقع HTML كامل يعمل على GitHub Pages. لا يحتاج PHP ولا قاعدة بيانات.

## تفعيل نموذج التواصل — ملف واحد فقط

سجّل مجاناً في <https://web3forms.com> ببريدك، وستصلك `Access Key` فوراً.
افتح **`site-config.js`** في جذر المستودع وضعها هنا:

```js
WEB3FORMS_KEY: "ضع-المفتاح-هنا",
```

هذا هو الملف الوحيد الذي تعدّله — كل الصفحات الأربع والأربعون تقرأ منه.

قبل ضبط المفتاح، الضغط على «إرسال الطلب» يفتح بريد الزائر برسالة معبّأة تلقائياً
بأسمه وبريده وتفاصيل طلبه، فلا يضيع عليك عميل.

## المحتويات

```
site-config.js      ← الإعدادات (المفتاح وعنوان الرسالة)
index.html          يحوّل الزائر إلى لغته تلقائياً
en/  ar/            نسختا الموقع، ٢١ صفحة لكل لغة
build/              ملفات CSS و JS
uploads/            صورك
404.html            صفحة الخطأ
sitemap.xml         خريطة الموقع
.nojekyll           ضروري — يمنع GitHub من معالجة الملفات
```

## تعديل المحتوى

النصوص مكتوبة داخل ملفات HTML مباشرة:

| ما تريد تغييره | الملف |
|---|---|
| العنوان الرئيسي والإحصاءات | `en/index.html` و `ar/index.html` |
| خدمة معيّنة | `en/services/اسم-الخدمة/index.html` |
| الأسعار | ابحث عن `$349` في ملفات `packages` و `services` |
| السيرة الذاتية | `en/resume/index.html` |

**تنبيه:** هذه النسخة منفصلة عن مشروع لارافيل. أي تعديل هنا لن ينتقل تلقائياً
إلى النسخة الكاملة. أرسل لي التعديلات لأطبّقها على النسختين معاً.

## عند شراء الدومين

```bash
bash ../scripts/set-site-url.sh https://mohamedabdalgader.com
```

ثم أنشئ ملف `CNAME` في الجذر يحوي اسم الدومين، واضبط سجلات DNS كما في دليل
GitHub Pages.
